# 🪪 Business Card

My personal digital business card, and my first project on the Scrimba Frontend Developer Career Path.

**🔗 Live demo:** https://faris471.github.io/business-card/

## Built with

- HTML5
- CSS3 (Flexbox)

## Run it locally

```bash
git clone https://github.com/Faris471/business-card.git
```

Then open `index.html` in your browser.

## What I learned

- Structuring a page with semantic HTML
- Laying out content side by side with Flexbox
- Styling images (rounded avatar) and text with CSS
